# 一次反复打磨的经验

这些是经验，不是所有婚礼的固定风格或参数。私人原片、信息、歌曲和个人轮廓不随技能分发。

| 问题 | 原因 | 改法 |
|---|---|---|
| 换歌也不影响播放 | 固定时长换照片 | 从真实攻击点建立事件，分段校正相位，落稳卡拍 |
| 纸片抽搐 | 每拍跳一下后停住 | 多拍连续整体运动，强调拍只给有意义的变化 |
| 越抠越怪 | 困难照片反复收紧/扩张 | 换适合照片，保全身体，必要时整张撕纸 |
| 只有胶片框 | 把例子当唯一要求 | 少量协调边框，按横竖构图编排 |
| 黑底变灰 | 无必要全屏发光 | 幕底保持指定纯色，局部有意义光效 |
| 间奏干巴 | 无画面动作发展 | 真实原声、照片接力、纸片互动、完整效果乐句 |
| 落日太多、效果太短 | 每镜头重置装饰 | 意象选择、多种效果、独立时钟跨镜头 |
| 特效都靠边 | 只最大化空白面积 | 屏内安全边界和中心倾向，检查完整轮廓 |
| 清单齐却像漏图 | 展示太短、代理错配 | 重扫目录，逐图对照编码文件，延长完整可见时间 |

本案例最终约四分十四秒，使用一百四十份获准素材；这只是案例规模。真正提升来自把音乐、照片可见时间、动作和效果放进统一时钟。

有些效果后来延长到约五至十秒并跨照片切换，体现完整动作生命周期；这不是其他影片的硬性时长。

剪辑教程值得借鉴的是可恢复工程、局部重渲染、包装/字幕分层、反复检查真实导出。口播教程的自动删静音、最后铺BGM、固定极低音乐电平不适合直接套到以歌曲为主的婚礼影片。
