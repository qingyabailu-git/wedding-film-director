# 纸片、布局、效果

## 选图先于抠图

选择两人互动清楚、身体完整、手臂易分离、姿态适合布局的照片。原图缺失的身体不能靠生成来冒充原照。连续多次窄抠切手臂、宽抠形成大灰块，说明该换照片。

可用完整人物宽松剪边；两人连同近旁环境组成一块纸；或整张照片做撕纸边。纸感来自纤维边、轻微落影和整体动作，不必把人物单独挖出来。

实际图像编辑/生成使用当前工具和对应技能，保持原人物身份、脸、服装与肢体。先放大检查发丝、面纱、肩臂、牵手、花束、裙摆、鞋，再缩至最终尺寸看整体。能力不足用整张纸片，不能交残缺人物。

边缘不规则但连贯，避免规律锯齿、巨大白环和几何凸包。落影局部、柔和，不能把纯黑幕底改成整屏灰色。

## 动作语法

整体纸片绕稳定支点平移/旋转，周期跨数拍，少量相位差让两人呼应。跨切镜头延续相位。关键动作有预备、加速、落点、跟随、安定；低幅连续漂移和强调拍动作独立控制，不做逐拍跳高归零。

## 布局与字体

先分配照片、人物、标题、歌词区域，再加装饰。保护运动后的实际边界，包含阴影/描边；转场同时保护出入两组。

竖图用竖幅条带/双联，横图用横向或上下呼应；混合方向以一主一辅处理。保存裁切焦点与主体安全区，必要时 contain，不盲目 cover。避免大白边、错落无序基线、溢出屏幕。

少量协调边框家族可选：胶片齿孔、角贴、窄边手写日期、轻撕边、简洁双联。“胶片”是用户举例，不是全片唯一解。

字体检查中文覆盖与现场可读性。标题可轻扫光/笔画显现，歌词保持稳定。字体和外部素材来源及许可记在项目。

## 特效是完整动作句

每个效果有独立时钟：预备 → 展开 → 看清 → 尾迹，可跨照片切换。短镜头可承接烟花余烬，不需要每切一张图重开特效。

| 模块 kind | 用法与限制 |
|---|---|
| fireworks | 高潮/欢庆；升空后在已确认重拍开花，留尾迹 |
| sunset | 晚霞/温暖；减少重复 |
| bloom | 花束/温柔；留足展开时间 |
| hearts | 对视/靠近；有呼应，不是固定小图标 |
| rays | 情绪提升；不盖脸或文字 |
| ribbon | 持续旅程；轨迹跨切换延续 |
| planes | 旅行/奔赴；方向呼应接力 |
| ripples | 安静乐段；缓慢发展 |
| confetti | 欢庆/结尾；低密度、消退后循环 |
| rings | 约定/结婚；靠拢动作，主体仍是照片 |

搜索完整轮廓能放下的内部留白，综合尺寸、中心倾向、避让、跨镜头稳定。只最大化空白面积会反复选角落。遮罩是最后防线；半朵花被擦掉应重新布局。可以在另一处留白加一两个安静陪衬，不机械填满黑色。

模块支持显式时间、独立效果计划和当前保护矩形回调，详见 [数据与工具](data-and-tools.md)。使用模块前设计位置和生命周期，它不自动知道歌词意义或照片位置。
