# 素材、故事和参考片

## 素材账本

源目录保持只读，输出另放，防止把代理和缩略图当作新增素材。扫描照片/视频及用户改名、新增文件，无法解码项单列。注意 HEIC/RAW 解码器、EXIF 方向和视频旋转信息。

每项记录稳定 ID、原路径、当前文件名、标题线索、显示尺寸、方向、媒体类型、时长、处理状态。代理图保留来源 ID 与视频取帧时间。不要把文件排序序号作为永久身份。

同路径可沿用身份；新路径且同大小/时间戳只作为改名候选，通过图像对照和必要哈希抽查确认后提交映射。同大小视频不一定相同。保留排除理由，不能重新扫描后复活用户撤回的内容。

实际查看所有图片与视频代表帧；视频还要查看动作和声音，不能用海报帧代替整段。寻找对视、牵手、转身、奔跑、旅行和共同兴趣等剪辑动作。

## 叙事

标题提供事实线索，用户指定顺序和音乐情绪决定影片编排。“素材日期”和“影片顺序”分别记录，重排不修改日期事实。用户明确的先后关系写入约束，避免下次按文件名排序又还原。

可用结构：欢迎 → 日常/相识 → 共同经历 → 更亲密片段 → 婚纱/约定 → 婚礼/致谢。没有素材支持的章节直接不用。婚纱照可写克制的情绪短句，生活标题优先忠实采用文件名，不虚构事件。歌词、故事标题、开场欢迎语分层管理。

## 参考片连续动效

选双人纸片、照片组合、高潮、间奏和结尾的代表短段。正常播放再低速查看，用 `reference_strip.py` 导出连续序列。可变帧率使用真实 PTS；平均 FPS 不能冒充每帧时间。

| 项目 | 观察内容 |
|---|---|
| 主体 | 整块纸、单人、双人、照片组还是摄影机在动？ |
| 支点 | 围绕脚底/中心？两人同相还是稍有滞后？ |
| 时间 | 预备、移动、落稳、回弹、停留各占多少拍？ |
| 接力 | 新照片怎样接过视觉中心，旧照片何时退出？ |
| 音乐 | 动作峰值对准鼓击、人声还是长音？ |
| 延续 | 装饰是否跨镜头，尾迹是否被截断？ |
| 构图 | 人物、文字、照片怎样分配空间？ |

定量复现可手选区域，用特征点光流和鲁棒仿射估计平移/角度/缩放，排除其他运动，记录内点和误差。跟踪失败时回看原片，不把噪声当轨迹。

提炼“整组缓摆、四拍接力、照片落稳后翻页”之类机制。不要只复制撕纸边而遗漏动作关系，也不要复制参考人物和不相关内容。
